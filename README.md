#### f(x,y):
чтобы подогнать f(x,y) нужно взять **оператор Лапласа от u_test** => 
f_test(x,y) = -2*((y^4+4x^2y^2)cos(2xy^2)+xsin(2xy^2))

#### Граничные условия
подставляем в u_test(x,y) по очереди x=a, x=b, y=c, y=d
и получаем 4 функции:
nu1 = 0

# ММН
### в чем заключается ММН?
1) выбираем **начальное приближение v^(0)** во внутренних узлах, например **нулевое**
2) для текущего состояния поверхности v, проверяем, насколько сильно не выполняется равенство в каждом узле:
		**r^(k) = Av^(k)-f**, если r = 0, значит решение идеальное
3) меняем значение в узлах так, чтобы ошибка r стала меньше, как выглядит шаг:
		**v^(k+1)=v^(k)-tao(k-1)* r^(k)**
	мы выбираем такое тао, который минимизирует норму невязки на следующем шаге
4) **tao(k+1) = scal(Ar^(k),r^(k))/scal(Ar^(k),Ar^(k))**


## Как установить

### Компиляция C++ кода:
``` powershell
mkdir build
cd build
cmake ..
cmake --build . --config Release

```
В папке build/Release появится calculate.exe, этот .exe нужно перенести в папку, где лежит maim.py

### Установка необходимых файлов main.py:
``` powershell
cd python
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

## Запуск
В одной папке должны лежать файлы: 
main.py, design.ui, calculate.exe
